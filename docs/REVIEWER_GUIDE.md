# 외부 검토자를 위한 3분 가이드

SEA Ops Arena는 **AI가 제안한 행동을 실제 운영 관점에서 비교·검증하기 위한 공개 벤치마크 환경**입니다.

이 저장소를 처음 보는 분이라면 아래 순서로 확인하는 것을 권장합니다.

## 1. 이 저장소가 보여 주는 것

현재 공개판에는 다음 기능이 실제 코드와 테스트로 구현되어 있습니다.

- 4개 운영 영역의 12개 공개 합성 시나리오
- 동일 시나리오에 여러 판단 결과를 적용하는 비교 실행
- 판단 일치율, 불필요 실행, 필요한 실행 누락, 실행 성공률 측정
- 동일 출처의 여러 반복 결과를 이용한 판단 안정성 측정
- 입력 파일 SHA-256 기반 재현 식별
- 결과 보고서와 manifest 생성
- 실제 외부 결과용 최소 공개 포맷
- 공개 결과와 정확한 시나리오 버전을 묶는 SHA-256 검증
- 원본 로그를 복사하지 않고 사용할 수 있는 공개 결과 템플릿
- 자동 테스트와 공개 릴리스 감사

GitHub Actions에서는 단위 테스트뿐 아니라 단일 평가, 비교, 반복 평가, 결과 템플릿 생성까지 실제 CLI 경로를 확인합니다.

## 3. 결과를 볼 때 중요한 점

Arena는 **“명령이 실행에 성공했는가”와 “그 명령을 실행하는 판단이 적절했는가”를 구분**해서 봅니다.

예를 들어 어떤 응답 방식이 실행한 모든 작업을 기술적으로 성공시켰더라도, 실행하지 않아야 할 요청까지 실행했다면 `불필요 실행`이 증가합니다.

따라서 단순 성공률 하나만으로 운영형 AI의 품질을 표현하지 않고 여러 공개 관찰값을 나누어 제공합니다.

## 4. 현재 결과의 한계

저장소에 포함된 기본 결과는 **합성 시나리오와 고정 응답으로 만든 기능 검증용 예시**입니다.

따라서 현재 예제 수치는 다음을 의미하지 않습니다.

- 실제 SEA 성능
- 특정 상용 AI 모델의 성능
- 실제 기업·공장·시설의 운영 성능
- 특정 산업에 대한 안전 인증

현재 공개 예시는 Arena가 결과를 어떻게 입력하고, 비교하고, 반복 검증하고, 재현하는지를 확인하기 위한 것입니다.

## 5. 왜 내부 구현이 보이지 않나

이 저장소의 목적은 특정 비공개 시스템의 내부 설계를 공개하는 것이 아니라 **외부에서 검증할 수 있는 입력·최종 결과·평가 표면을 제공하는 것**입니다.

따라서 Arena는 연결된 시스템의 내부 상태, 정책, 판단 과정이나 구현 구조를 요구하지 않습니다. 공개 저장소만으로 벤치마크 실행과 결과 검토가 가능하도록 경계를 분리했습니다.

## 6. 현재 개발 단계

현재 공개판은 **벤치마크 실행 → 결과 비교 → 재현 → 반복 안정성 → 안전한 외부 결과 입력 경계**까지 구현된 단계입니다.

다음 공개 단계는 이 구조를 유지한 채 실제 공개 가능한 외부 결과를 축적하고, 시나리오 폭과 결과 표현을 확장하는 것입니다.

공개판의 개발 방향은 [`ROADMAP.md`](ROADMAP.md)에서 확인할 수 있습니다.
