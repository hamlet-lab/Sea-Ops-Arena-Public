# 외부 검토자를 위한 3분 가이드

SEA Ops Arena는 **AI가 제안한 행동을 실제 운영 관점에서 비교·검증하기 위한 공개 벤치마크 환경**입니다.

## 1. 현재 실제로 구현된 것

현재 공개판 v0.6에는 다음 기능이 코드와 테스트로 구현되어 있습니다.

- 4개 운영 영역의 12개 공개 합성 시나리오
- 여러 판단 결과의 동일 조건 비교
- 판단 일치율, 불필요 실행, 필요한 실행 누락, 실행 성공률 측정
- 동일 출처 반복 결과의 판단 안정성 측정
- 입력 파일 SHA-256 기반 재현 식별
- 실제 외부 결과용 최소 공개 포맷
- 평가용 시나리오와 결과의 SHA-256 결합
- **평가 정답이 제거된 `arena-input-pack-v2` 생성**
- 입력팩 안에 공개 과제 정의와 no-tools baseline 제약 고정
- 실제 결과와 입력팩 전체의 SHA-256 결합
- 원본 로그를 복사하지 않는 결과 템플릿
- 자동 테스트와 공개 릴리스 감사

## 3. 정답이 공개되어 있는데 평가가 가능한 이유

평가 계산을 외부에서도 재현할 수 있도록 평가용 시나리오에는 기대 판단이 포함될 수 있습니다.

하지만 실제 판단 생성 시에는 그 파일을 모델에게 주지 않습니다.

`arena-input-pack-v2`는 다음을 제거합니다.

- 기대 판단
- 평가 태그와 메모
- 실행 기대 결과
- 임의 metadata와 외부 context 참조

대신 모델이 수행할 **공개 과제 정의와 출력 계약, no-tools 실행 제약**까지 입력팩 안에 함께 고정합니다.

실제 결과는 평가용 시나리오 SHA-256과 입력팩 SHA-256을 모두 기록합니다. 따라서 외부 검토자는 모델이 어느 문제와 어느 공개 지시 조건을 기준으로 결과를 냈는지 확인할 수 있습니다.

## 4. 결과를 볼 때 중요한 점

Arena는 **“실행 자체가 성공했는가”와 “그 실행을 선택한 판단이 적절했는가”를 분리**합니다.

실행한 작업이 모두 기술적으로 성공했더라도 실행하지 않아야 할 요청까지 실행했다면 `불필요 실행`이 증가합니다.

따라서 하나의 종합점수보다 여러 공개 관찰값을 나누어 보여 줍니다.

## 5. 현재 결과의 한계

현재 저장소에 포함된 결과는 **합성 시나리오와 고정 응답으로 만든 기능 검증용 fixture**입니다.

현재 예제 수치는 실제 SEA 성능, 특정 상용 AI 모델 성능, 실제 산업 운영 성능 또는 안전 인증을 의미하지 않습니다.

## 6. 왜 내부 구현이 보이지 않나

이 저장소의 목적은 비공개 시스템의 내부 설계를 공개하는 것이 아니라 **외부에서 검증해야 할 입력·최종 결과·평가·재현 표면을 제공하는 것**입니다.

외부 검토자는 내부 기술을 알지 못해도 다음을 확인할 수 있습니다.

- 어떤 평가 문제를 사용했는가
- 판단 대상이 실제로 어떤 정답 비노출 입력팩을 봤는가
- 어떤 과제·도구 사용 조건이 적용됐는가
- 어떤 최종 판단이 나왔는가
- 같은 기준에서 어떻게 평가됐는가
- 반복할 때 결과가 얼마나 안정적인가

## 7. 현재 개발 단계

현재 공개판은 **벤치마크 실행 → 비교 → 재현 → 반복 안정성 → 안전한 외부 결과 포맷 → 정답 비노출 입력 → 공개 baseline 조건 고정**까지 구현된 단계입니다.

다음 공개 단계는 이 프로토콜을 사용해 첫 실제 외부 baseline 결과를 축적하는 것입니다.
