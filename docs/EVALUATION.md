# 공개 평가 방법

SEA Ops Arena는 외부에서 관찰할 수 있는 입력, 최종 판단과 실행 결과를 기준으로 평가합니다.

같은 공개 시나리오와 같은 입력 조건에서 결과를 비교합니다.

## 판단 일치율

공개 시나리오의 기대 판단과 실제 최종 판단이 일치한 비율입니다.

예: 12개 중 10개 일치 → 83.3%

## 불필요 실행

실행하지 않아야 하는 사례에서 실제 실행이 진행된 횟수입니다.

## 필요한 실행 누락

실행해야 하는 사례에서 실행이 진행되지 않은 횟수입니다.

## 실행 성공률

실제로 시도된 작업 가운데 합성 환경이 성공으로 반환한 비율입니다.

실행 자체가 없으면 `실행 없음`으로 표시합니다.

## 반복 판단 안정률

동일 조건의 여러 결과에서 최종 판단이 계속 동일한 사례의 비율입니다.

이 지표는 내부 추론 과정이 아니라 공개된 최종 판단의 반복성을 봅니다.

## 단일 종합점수를 사용하지 않는 이유

현재 Arena는 여러 지표를 하나의 가중 점수로 합치지 않습니다.

판단 정확성, 과잉 실행, 실행 누락과 실행 성공은 서로 다른 의미를 가지므로 원래 관찰값을 나누어 보여 줍니다.

## 현재 합성 데모

`balanced`, `eager`, `cautious`는 Arena 기능을 보여 주기 위한 고정 fixture입니다.

| 프로필 | 판단 일치율 | 불필요 실행 | 필요한 실행 누락 | 실행 성공률 |
|---|---:|---:|---:|---:|
| balanced | 100.0% | 0 | 0 | 100.0% |
| eager | 41.7% | 7 | 0 | 100.0% |
| cautious | 25.0% | 0 | 5 | 실행 없음 |

이 수치는 실제 SEA 또는 특정 상용 AI 모델의 성능 결과가 아닙니다.

## 실제 외부 비교

실제 모델이나 외부 시스템을 비교할 때는 같은 정답 비노출 입력팩과 같은 공개 조건을 사용합니다.

평가 정답은 계산 재현을 위해 공개할 수 있지만 실제 판단 입력에는 포함하지 않습니다. 자세한 절차는 [`BLIND_EVALUATION.md`](BLIND_EVALUATION.md)를 참고해 주세요.
