# 공개 평가 방법

SEA Ops Arena의 공개판은 **외부에서 관찰할 수 있는 입력·판단 결과·실행 결과만으로 평가**합니다.

이 문서는 공개 벤치마크의 점수가 무엇을 뜻하는지 설명합니다. SEA 또는 연결된 다른 의사결정 시스템의 내부 평가 기준을 설명하는 문서가 아닙니다.

## 기본 원칙

같은 공개 시나리오와 같은 요청을 주고 결과를 비교합니다. 각 합성 사례에는 누구나 확인할 수 있는 공개 기대값이 포함됩니다.

현재 공개판은 다음 네 가지를 중심으로 집계합니다.

### 1. 판단 일치율

공개 시나리오에 적힌 기대 판단과 실제로 반환된 공개 판단 결과가 얼마나 일치했는지 계산합니다.

예를 들어 3개 사례 중 2개가 일치했다면 판단 일치율은 66.7%입니다.

### 2. 불필요 실행 수

공개 기대값상 실행하지 않아야 하는 사례에서 실제 실행이 진행된 횟수입니다.

이 값은 공개 벤치마크 안에서 관찰된 실행 여부만 셉니다. 외부 시스템이 내부에서 어떤 이유로 결론을 냈는지는 평가하지 않습니다.

### 3. 필요한 실행 누락 수

공개 기대값상 실행해야 하는 사례에서 실행이 진행되지 않은 횟수입니다.

지나치게 보수적인 응답이 작업 수행을 막는 경우도 함께 볼 수 있도록 만든 지표입니다.

### 4. 실행 성공률

실제로 시도된 작업 가운데 공개 합성 환경이 성공으로 반환한 비율입니다.

실행 자체가 없으면 성공률을 억지로 0%로 표시하지 않고 `실행 없음`으로 구분합니다.

## 왜 단일 점수로 합치지 않나

현재 공개판은 네 지표를 하나의 종합점수로 강제 합산하지 않습니다.

하나의 숫자로 합치려면 각 항목의 가중치를 정해야 하고, 그 가중치는 용도에 따라 달라질 수 있기 때문입니다. 대신 원래 관찰값을 그대로 보여 주어 외부 검토자가 결과를 직접 해석할 수 있게 합니다.

## 현재 데모의 성격

저장소에 포함된 `balanced`, `eager`, `cautious` 프로필은 실제 AI 모델이나 SEA의 결과가 아닙니다. Arena의 실행·집계·보고 기능을 재현하기 위해 미리 정해 둔 합성 응답입니다.

따라서 데모 숫자는 제품 성능 주장이나 모델 비교 결과로 사용하지 않습니다.

## 앞으로의 공개 비교

실제 모델 비교를 추가할 경우에도 같은 원칙을 유지합니다.

- 동일한 공개 시나리오 사용
- 입력 조건과 버전 기록
- 결과 원문과 집계값 구분
- 실패 사례 포함
- 모델 이름과 실행 조건 명시
- 재현되지 않은 결과를 확정적 성능 수치로 표현하지 않음

핵심은 **결과는 검증 가능하게 공개하되, 외부 의사결정 시스템의 내부 구현은 평가 인터페이스 뒤에 남겨 두는 것**입니다.
