# 공개 개발 로드맵

이 문서는 SEA Ops Arena **공개판 자체**의 개발 방향을 설명합니다. SEA 또는 다른 비공개 시스템의 내부 개발 로드맵을 포함하지 않습니다.

## 현재 — v0.3

공개 벤치마크의 첫 비교·재현 단위를 구현했습니다.

- 공개 요청·판단 결과 계약
- 외부 시스템 연결용 최소 인터페이스
- 합성 실행 환경
- JSON 시나리오 입력
- JSON 판단 결과 입력
- 4개 업무 영역, 12개 공개 합성 사례
- 판단 일치율 / 불필요 실행 / 필요한 실행 누락 / 실행 성공률 집계
- 여러 판단 결과 파일의 동일 조건 비교
- Markdown / JSON 결과 보고서
- 입력 파일 SHA-256 기반 재현 실행 식별자
- `manifest.json` / `report.md` / `results.json` 실행 결과 묶음
- 판단 결과 파일의 누락·불필요 ID 사전 검증
- 자동 테스트 CI
- 공개/비공개 경계 및 시나리오 작성 원칙 문서화

현재 저장소에 포함된 예시는 구조와 재현성을 검증하기 위한 **합성 데이터와 고정 응답**입니다. 실제 모델 또는 SEA 성능 결과가 아닙니다.

## 다음 — 기록된 외부 모델 결과 입력

Arena가 외부 AI 모델 또는 에이전트의 결과를 **공개 가능한 결과 파일** 형태로 받아 같은 시나리오에서 비교할 수 있도록 확장합니다.

이 단계의 목표는 모델 호출 코드 자체를 공개하는 것이 아니라, 공개가 허용된 결과만 공통 입력 형식으로 정규화하는 것입니다.

공개 결과 파일에 포함할 수 있는 정보의 예:

- 공개 모델명 및 버전
- 공개 실행 날짜
- 시나리오 버전
- 반복 식별자
- 공개 가능한 판단 결과
- 공개 가능한 실행 조건

다음 항목은 기본적으로 공개 결과 파일에 저장하지 않습니다.

- 비공개 시스템 프롬프트
- 내부 시스템 메시지
- 내부 추론 또는 작업 trace
- 비공개 상태·정책·판단 자료
- API 키, 토큰, 내부 URL, 파일 경로
- 공개 검토를 거치지 않은 원본 로그

모델 호출과 Arena 집계를 분리해, 공개 가능한 결과만 저장한 뒤에도 동일한 Arena에서 다시 평가할 수 있도록 합니다.

## 이후 — 반복 실험과 변동성

동일 조건의 반복 실행을 지원하고 평균값뿐 아니라 결과의 변동도 함께 기록합니다.

- 반복 실행
- 공개 실행 식별자
- 모델별 비교표
- 실패 사례 목록
- 공개 원시 결과와 요약 결과의 연결

반복 실험에서도 비공개 내부 trace를 재현 자료로 요구하지 않습니다.

## 이후 — 시나리오 확장

현재 12개 합성 사례를 기반으로 공개 문제의 폭을 넓힙니다.

후보 범위:

- 시간 순서가 중요한 요청
- 연속된 여러 작업
- 실행 실패가 포함된 사례
- 여러 요청 사이의 공개 충돌
- 서로 다른 업무 영역을 잇는 합성 사례

추가 시나리오도 특정 비공개 정책이나 내부 구조를 복제하지 않고, 외부에서 기대값을 독립적으로 이해할 수 있는 공개 문제로 작성합니다.

## 이후 — 공개 결과 시각화

코드를 읽지 않는 사람도 결과를 이해할 수 있도록 정적 리포트와 간단한 시각화를 추가합니다.

우선순위는 화려한 대시보드보다 **결과의 출처와 재현 경로가 명확한 화면**입니다.

## 유지되는 원칙

기능이 늘어나더라도 다음 원칙은 유지합니다.

1. 공개 벤치마크는 독립적으로 재현 가능해야 합니다.
2. 실제 결과와 합성 예시를 명확히 구분합니다.
3. 실패 사례를 숨기지 않습니다.
4. 공개 지표의 계산 방법은 설명할 수 있어야 합니다.
5. 외부 시스템의 비공개 내부 구현을 공개 벤치마크에 복제하지 않습니다.
6. 비공개 저장소의 Git 이력이나 내부 자료를 공개 저장소로 가져오지 않습니다.
7. 여러 공개 파일을 조합했을 때 비공개 구조를 역추론할 수 있는 정보도 공개하지 않습니다.
