# 공개 개발 로드맵

이 문서는 SEA Ops Arena **공개판 자체**의 개발 방향을 설명합니다. SEA 또는 다른 비공개 시스템의 내부 개발 로드맵을 포함하지 않습니다.

## 현재 — v0.2

공개 벤치마크의 최소 실행 단위를 구현했습니다.

- 공개 요청·판단 결과 계약
- 외부 의사결정 시스템 연결 인터페이스
- 합성 실행 환경
- JSON 시나리오 입력
- JSON 판단 결과 입력
- 공개 지표 집계
- Markdown / JSON 결과 보고서
- 합성 데모 3종
- 자동 테스트 CI
- 공개/비공개 경계 문서화

현재 예제는 구조와 재현성을 검증하기 위한 합성 데이터입니다.

## 다음 — 시나리오 확장

공개 시나리오를 여러 업무 영역으로 확대합니다.

목표는 특정 산업의 내부 시스템을 복제하는 것이 아니라, 다음과 같이 일반화할 수 있는 운영 상황을 충분히 다양하게 확보하는 것입니다.

- 정보가 충분한 요청과 부족한 요청
- 중복 요청
- 상충하는 요청
- 시간 순서가 중요한 요청
- 실행 성공과 실행 실패
- 연속된 여러 작업에서의 결과 변화

각 시나리오는 기대값과 평가 기준을 외부에서 확인할 수 있는 합성 사례로 작성합니다.

## 이후 — 실제 모델 결과 입력

Arena가 안정화되면 실제 AI 모델 또는 에이전트의 결과를 **기록된 공개 입력 파일** 형태로 받아 비교할 수 있게 확장합니다.

이 단계에서는 다음 정보를 함께 남기는 것을 목표로 합니다.

- 모델명 및 버전
- 실행 날짜
- 시나리오 버전
- 공개 입력
- 공개 출력
- 반복 횟수
- 실행 조건
- 집계 결과

모델 호출 자체와 벤치마크 집계를 분리해, 이미 생성된 결과도 동일한 Arena에서 다시 평가할 수 있도록 합니다.

## 이후 — 반복 실험과 비교

동일 조건의 반복 실행을 지원하고 평균값만이 아니라 변동도 함께 기록합니다.

- 반복 실행
- 시드 및 실행 식별자
- 모델별 비교표
- 실패 사례 목록
- 원시 결과와 요약 결과의 연결

## 이후 — 공개 결과 시각화

코드를 읽지 않는 사람도 결과를 이해할 수 있도록 정적 리포트와 간단한 시각화를 추가합니다.

우선순위는 화려한 대시보드보다 **결과의 출처와 재현 경로가 명확한 화면**입니다.

## 유지되는 원칙

기능이 늘어나더라도 다음 원칙은 유지합니다.

1. 공개 벤치마크는 독립적으로 재현 가능해야 합니다.
2. 실제 결과와 합성 예시를 명확히 구분합니다.
3. 실패 사례를 숨기지 않습니다.
4. 공개 지표의 계산 방법은 설명할 수 있어야 합니다.
5. 외부 시스템의 비공개 내부 구현을 공개 벤치마크에 복제하지 않습니다.
6. 비공개 저장소의 Git 이력이나 내부 자료를 공개 저장소로 가져오지 않습니다.
