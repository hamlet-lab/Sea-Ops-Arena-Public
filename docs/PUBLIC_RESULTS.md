# 공개 결과 파일 규칙

SEA Ops Arena는 실제 외부 모델·에이전트·사람·외부 시스템의 결과를 비교할 수 있도록 **공개 전용 결과 포맷**을 제공합니다.

이 포맷의 목적은 원본 실행 로그를 그대로 저장하는 것이 아니라, Arena 평가에 필요한 최소 결과만 남기는 것입니다.

## 기본 원칙

공개 결과 파일은 **허용된 필드만 저장하는 방식**을 사용합니다.

현재 `public-decision-set-v1`에서 허용하는 최상위 필드는 다음 다섯 가지뿐입니다.

- `schema_version`
- `label`
- `suite_sha256`
- `source`
- `decisions`

`source` 역시 다음 필드만 허용합니다.

- `kind`
- `model_name`
- `model_version`
- `recorded_at`
- `repeat_id`

이 목록에 없는 필드가 들어오면 로더가 실행 전에 오류를 발생시킵니다.

## 시나리오 파일과 결과 결합

실제 모델·사람·외부 시스템 결과에는 `suite_sha256`을 기록합니다.

이 값은 결과가 생성될 때 사용한 **공개 시나리오 JSON 파일 자체의 SHA-256**입니다. Arena는 현재 평가하려는 시나리오 파일의 SHA-256과 결과 파일의 값을 비교합니다.

둘이 다르면 평가를 중단합니다.

이 장치는 다음 실수를 막기 위한 것입니다.

- 시나리오가 수정된 뒤 예전 결과를 새 기준으로 평가
- 이름은 같지만 내용이 다른 시나리오 파일을 혼용
- 반복 실험 사이에 기준 파일이 바뀌었는데 같은 실험으로 취급

저장소에 포함된 `fixture` 예시는 설명 편의를 위해 `suite_sha256`을 생략할 수 있지만, 실제 외부 결과에는 필수입니다.

## 저장하지 않는 정보

공개 결과 파일에는 다음과 같은 원본 실행 정보를 넣지 않습니다.

- 비공개 프롬프트
- 시스템 메시지
- 내부 추론 또는 작업 로그
- 내부 상태·정책·구조 정보
- API 키나 인증 토큰
- 내부 URL 및 파일 경로
- 공개 검토를 거치지 않은 임의 metadata

필요한 정보가 생기면 임의 필드를 바로 추가하지 않고, 공개 필요성과 유출 가능성을 검토한 뒤 포맷 버전을 올려 명시적으로 추가합니다.

## 예시

```json
{
  "schema_version": "public-decision-set-v1",
  "label": "example-run",
  "suite_sha256": "<공개 시나리오 파일의 SHA-256>",
  "source": {
    "kind": "model",
    "model_name": "public-model-name",
    "model_version": "public-version",
    "recorded_at": "2026-09-02T02:00:00+09:00",
    "repeat_id": "run-001"
  },
  "decisions": {
    "request-001": "proceed",
    "request-002": "reject",
    "request-003": "defer"
  }
}
```

실제 실행 가능한 합성 예시는 `examples/results/`에 있습니다. 이 예시들은 실제 모델 결과가 아니라 포맷과 반복 평가 동작을 보여 주기 위한 fixture입니다.

## 지원하는 출처 종류

현재 `source.kind`는 다음 네 종류만 허용합니다.

- `fixture`: 저장소에 포함된 합성 고정 예시
- `model`: 공개 모델 결과
- `human`: 사람의 공개 판단 결과
- `external-system`: 기타 외부 시스템의 공개 결과

이 값은 결과의 출처를 구분하기 위한 공개 메타데이터일 뿐, 연결된 시스템의 내부 구조를 나타내지 않습니다.

## 반복 결과

같은 대상의 반복 실험은 파일을 하나로 합치지 않고 **반복마다 별도 공개 결과 파일**로 남깁니다.

각 파일에는 서로 다른 `source.repeat_id`를 사용합니다. 반복 평가 시 다음 정보가 동일해야 합니다.

- `label`
- `source.kind`
- `source.model_name`
- `source.model_version`
- `suite_sha256`이 가리키는 시나리오 파일

Arena는 반복마다 공개된 최종 판단만 비교합니다. 모든 반복에서 같은 판단을 낸 사례의 비율을 `반복 판단 안정률`로 계산하며, 내부 사고 과정이나 비공개 상태의 일관성을 의미하지 않습니다.

## 권장 공개 절차

실제 외부 결과는 다음 순서로 다루는 것을 권장합니다.

1. 모델 또는 외부 시스템 실행은 비공개 환경에서 수행합니다.
2. 공개할 시나리오 파일을 확정합니다.
3. 공개 결과 템플릿을 생성해 정확한 `suite_sha256`과 request ID 목록을 고정합니다.
4. 원본 로그를 복사하지 않고 최종 `proceed` / `reject` / `defer` 결과만 채웁니다.
5. Arena 로더와 커버리지 검사를 통과시킵니다.
6. 공개 저장소에 넣기 전 별도의 공개 경계 검토를 수행합니다.

## 기존 예제와의 관계

`examples/decisions/` 아래의 단순 JSON 파일은 Arena 동작을 빠르게 보여 주기 위한 합성 fixture 형식입니다.

실제 외부 결과를 저장하거나 장기적으로 배포할 때는 허용 필드와 시나리오 해시 결합을 적용하는 `public-decision-set-v1`을 사용합니다.
