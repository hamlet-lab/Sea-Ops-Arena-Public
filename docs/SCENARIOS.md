# 공개 시나리오

SEA Ops Arena의 공개 시나리오는 외부에서 같은 조건으로 다시 실행할 수 있도록 만든 합성 평가 문제입니다.

현재 공개 세트는 4개 운영 영역의 12개 사례로 구성됩니다.

| 영역 | 사례 수 | 예시 |
|---|---:|---|
| 고객지원 | 3 | 정상 요청, 입력 충돌, 정보 누락 |
| 사무 운영 | 3 | 정상 구매, 정보 누락, 중복 요청 |
| 재고 관리 | 3 | 정상 보충, 중복 작업, 수량 충돌 |
| 시설 운영 | 3 | 정기 점검, 대상 불일치, 경보 점검 |

## 판단 라벨

각 사례에는 `proceed`, `reject`, `defer` 중 하나의 공개 기대값이 있습니다.

- `proceed` : 제공된 정보로 실행 진행 가능
- `reject` : 제공된 정보만으로 실행하면 안 됨
- `defer` : 추가 확인이나 정보 해소가 먼저 필요함

이 값들은 Arena 결과 비교를 위한 공개 라벨입니다.

## 현재 Pack의 목적

현재 12개 사례는 다음처럼 단순하지만 운영에서 자주 나타나는 차이를 봅니다.

- 필요한 정보가 충분한 요청
- 서로 충돌하는 정보
- 판단에 필요한 정보 누락
- 이미 처리된 요청의 중복
- 대상 정보 불일치

모든 사례는 공개용 합성 데이터이며 특정 비공개 시스템의 실제 정책이나 내부 구현을 옮긴 것이 아닙니다.

## Pack 확장

앞으로 새로운 문제 유형을 시험할 필요가 생기면 별도 Pack으로 추가할 수 있습니다.

예:

- 연속 행동
- 실행 중 조건 변화
- 추가 확인이 필요한 요청
- 일부 실행 실패가 포함된 작업
- 여러 업무 영역이 연결된 문제

Public에는 검토가 끝난 Pack만 선택적으로 추가합니다.
