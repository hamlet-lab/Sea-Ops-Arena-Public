# 공개 합성 벤치마크 v2 비교 예시

아래 표는 `public_suite_v2.json`의 12개 합성 사례에 세 가지 **고정 예시 응답**을 적용했을 때의 결과입니다.

실제 AI 모델이나 SEA를 실행한 결과가 아닙니다.

| 예시 입력 | 판단 일치율 | 불필요 실행 | 필요한 실행 누락 | 실행 성공률 |
|---|---:|---:|---:|---:|
| `v2-balanced.json` | 100.0% | 0 | 0 | 100.0% |
| `v2-eager.json` | 41.7% | 7 | 0 | 100.0% |
| `v2-cautious.json` | 25.0% | 0 | 5 | - |

## 이 예시가 보여 주는 것

`v2-eager`는 시도한 실행 자체는 모두 합성 환경에서 정상적으로 처리되기 때문에 실행 성공률이 100%입니다. 하지만 실행하지 않거나 추가 확인해야 하는 사례까지 모두 진행해 **불필요 실행이 7회** 발생합니다.

반대로 `v2-cautious`는 실제 실행을 전혀 시도하지 않으므로 불필요 실행은 없지만, 진행해야 하는 공개 사례 **5건을 놓칩니다.**

즉 SEA Ops Arena는 단순히 “명령이 성공했는가”만 보는 대신, **그 실행이 애초에 적절했는지와 필요한 일을 놓치지 않았는지를 별도 관찰값으로 보여 줄 수 있습니다.**

이 수치는 Arena의 측정 방식을 설명하기 위한 합성 예시이며 실제 제품 성능 주장에 사용하지 않습니다.
