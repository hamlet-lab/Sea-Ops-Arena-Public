# 공개 합성 데모 결과 예시

> 아래 수치는 실제 AI 모델 또는 SEA의 성능 결과가 아닙니다. 공개 Arena의 실행·집계·보고 기능을 확인하기 위해 미리 정해 둔 세 가지 응답 프로필을 같은 합성 시나리오에 적용한 결과입니다.

## 한눈에 보기

| 예시 프로필 | 판단 일치율 | 불필요 실행 | 필요한 실행 누락 | 실행 성공 |
|---|---:|---:|---:|---:|
| balanced | 100.0% | 0건 | 0건 | 1/1 |
| eager | 33.3% | 2건 | 0건 | 3/3 |
| cautious | 33.3% | 0건 | 1건 | 실행 없음 |

## 이 표가 보여 주는 것

`balanced`, `eager`, `cautious`는 모델명이 아니라 **고정된 예시 응답 패턴**입니다.

- `balanced`는 세 합성 사례의 공개 기대값과 동일한 응답을 반환합니다.
- `eager`는 모든 요청을 진행합니다. 그 결과 실행하지 않아야 하는 두 사례에서도 실행이 발생합니다.
- `cautious`는 모든 요청을 보류합니다. 그 결과 실행이 필요한 한 사례가 진행되지 않습니다.

이 비교의 목적은 어떤 전략이 우수하다고 주장하는 것이 아니라, **같은 시나리오에서 서로 다른 행동 패턴을 Arena가 어떻게 분리해 기록하는지** 보여 주는 것입니다.

## 재현

```bash
python -m sea_ops_arena.demo --profile balanced
python -m sea_ops_arena.demo --profile eager
python -m sea_ops_arena.demo --profile cautious
```

기계 판독 가능한 결과가 필요하면 `--format json`을 추가할 수 있습니다.
