# SEA Ops Arena

SEA Ops Arena는 **AI가 실제 운영 환경에 영향을 주는 행동을 제안할 때, 그 결과를 안전하고 재현 가능한 방식으로 검증하기 위한 공개 벤치마크·평가 환경**입니다.

이 저장소에는 SEA의 내부 구현체가 아니라, 외부에서 확인하고 반복 실행할 수 있는 **Arena(검증 환경)**만 공개합니다.

## 현재 공개판에서 할 수 있는 것

현재 공개판은 4개 운영 영역의 **12개 합성 시나리오**를 동일한 형식으로 실행하고 비교할 수 있습니다.

- JSON 기반 공개 시나리오 묶음 실행
- JSON 기반 공개 판단 결과 입력
- 동일한 시나리오에 여러 결과를 넣어 한 표에서 비교
- 동일 출처 결과의 반복 실행과 판단 안정성 집계
- 실행 여부와 합성 환경 결과 기록
- 판단 일치율 집계
- 불필요 실행 횟수 집계
- 필요한 실행 누락 횟수 집계
- 실행 성공률 집계
- 한국어 Markdown 또는 JSON 결과 출력
- 입력 파일 SHA-256 기반의 재현 가능한 실행 식별자 생성
- `manifest.json` + `report.md` + `results.json` 결과 묶음 저장
- 판단 결과 파일의 누락·불필요 ID 사전 검증
- 실제 외부 결과와 시나리오 파일의 SHA-256 결합 검증
- 허용된 필드만 받는 외부 결과용 공개 포맷
- GitHub Actions를 통한 테스트와 CLI 재현 경로 자동 검증

현재 포함된 결과는 **실제 AI 모델이나 SEA의 성능 결과가 아닙니다.** Arena의 실행·비교·재현 방식을 보여 주기 위해 만든 합성 시나리오와 고정 응답입니다.

## 12개 공개 시나리오

대표 공개 세트는 다음 네 영역으로 구성됩니다.

| 영역 | 사례 수 | 예시 |
|---|---:|---|
| 고객지원 | 3 | 정상 요청, 입력 충돌, 정보 누락 |
| 사무 운영 | 3 | 정상 구매, 정보 누락, 중복 요청 |
| 재고 관리 | 3 | 정상 보충, 중복 작업, 수량 충돌 |
| 시설 운영 | 3 | 정기 점검, 대상 불일치, 경보 점검 |

이 사례들은 공개용으로 새로 만든 합성 문제이며, 비공개 시스템의 정책이나 내부 규칙을 복제하지 않습니다. 자세한 작성 원칙은 [`docs/SCENARIOS.md`](docs/SCENARIOS.md)에 설명되어 있습니다.

## 빠르게 실행해 보기

Python 3.11 이상 환경에서 설치합니다.

```bash
python -m pip install -e .
```

12개 공개 시나리오를 실행합니다.

```bash
sea-ops-arena \
  --suite examples/scenarios/public_suite_v2.json \
  --decisions examples/decisions/v2-balanced.json
```

## 여러 결과를 한 번에 비교

같은 12개 시나리오에 세 가지 고정 예시 결과를 적용해 공개 지표를 나란히 볼 수 있습니다.

```bash
sea-ops-arena-compare \
  --suite examples/scenarios/public_suite_v2.json \
  --decisions \
    examples/decisions/v2-balanced.json \
    examples/decisions/v2-eager.json \
    examples/decisions/v2-cautious.json
```

Arena는 임의의 가중 종합점수나 순위를 만들지 않고 원래 관찰값을 그대로 비교합니다. 예시 결과는 [`examples/V2_COMPARISON.md`](examples/V2_COMPARISON.md)에서 볼 수 있습니다.

## 반복 결과의 안정성 보기

같은 출처·같은 모델 버전에서 여러 번 기록한 엄격 공개 결과를 묶어 반복 판단 안정성을 확인할 수 있습니다.

```bash
sea-ops-arena-repeat \
  --suite examples/scenarios/public_suite_v2.json \
  --results \
    examples/results/v2-balanced.public.json \
    examples/results/v2-repeat-002.public.json \
    examples/results/v2-repeat-003.public.json
```

반복 평가는 평균 판단 일치율뿐 아니라 **모든 반복에서 같은 최종 판단을 낸 사례의 비율**을 별도로 보여 줍니다. 이 값은 공개된 최종 판단의 변동만 측정하며 내부 사고 과정이나 비공개 상태를 측정하지 않습니다.

## 재현 가능한 공개 결과 묶음

`--output-dir`을 지정하면 공개 입력 파일의 해시와 실행 결과를 함께 저장합니다.

```bash
sea-ops-arena \
  --suite examples/scenarios/public_suite_v2.json \
  --decisions examples/decisions/v2-balanced.json \
  --output-dir runs
```

생성되는 디렉터리에는 다음 파일이 들어갑니다.

- `manifest.json` — 입력 파일명, SHA-256, 실행 식별자, 공개 요약 지표
- `report.md` — 사람이 읽기 쉬운 한국어 결과 보고서
- `results.json` — 후속 분석용 구조화 결과

같은 시나리오 파일과 같은 판단 결과 파일을 사용하면 같은 `run_id`가 생성됩니다. manifest에는 호스트명, 환경변수, 내부 시스템 경로 또는 비공개 판단 과정은 기록하지 않습니다.

## 외부 결과를 공개할 때

실제 외부 모델·사람·외부 시스템의 결과를 저장할 때는 `public-decision-set-v1` 형식을 사용합니다.

실제 외부 결과에는 해당 결과가 생성된 **정확한 공개 시나리오 파일의 SHA-256**을 `suite_sha256`으로 기록해야 합니다. 현재 시나리오 파일과 해시가 다르면 Arena는 평가를 거부합니다.

이 형식은 **허용된 필드만 통과**합니다. 임의 metadata나 원본 프롬프트·시스템 메시지·로그·내부 trace 등을 파일에 추가하면 로더가 거부합니다. 합성 예시는 `examples/results/`, 상세 규칙은 [`docs/PUBLIC_RESULTS.md`](docs/PUBLIC_RESULTS.md)에 있습니다.

자세한 실행 방법은 [`docs/QUICKSTART.md`](docs/QUICKSTART.md), 평가 지표의 의미는 [`docs/EVALUATION.md`](docs/EVALUATION.md)를 참고해 주세요.

## 공개 구조

Arena는 연결된 의사결정 시스템이 내부에서 어떤 방식으로 판단하는지 알 필요가 없습니다. 로컬 시스템, 원격 시스템, 사람의 판단, 규칙 기반 시스템, 비공개 시스템 등 다양한 방식을 동일한 공개 인터페이스로 연결할 수 있습니다.

```text
AI 모델 / 에이전트
        |
        v
    실행 요청
        |
        v
 외부 시스템 연결부   <---- 내부 구현 비공개
        |
        v
    공개 판단 결과
        |
        v
  공개 합성 환경
        |
        v
 평가 결과 / 공개 결과 묶음
```

## 무엇을 공개하나

이 저장소의 공개 범위는 의도적으로 제한되어 있습니다.

- 공개 시나리오 및 벤치마크 형식
- AI/에이전트 결과 연결용 공통 어댑터
- 외부 시스템과 연결되는 최소 인터페이스
- 공개 가능한 최종 판단 결과 형식
- 합성 환경 실행 결과
- 일반적인 점수화·비교·반복성·보고서·재현 도구

## 무엇을 공개하지 않나

이 저장소는 다음 내용을 공개하지 않습니다.

- SEA 내부 구현 코드
- 내부 상태 표현 방식
- 비공개 정책·판단·권한 처리 로직
- 내부 검증 및 실행 제어 구조
- 비공개 아키텍처 문서
- 연구·특허 관련 비공개 자료
- 실제 운영 환경의 연결 정보 및 내부 시스템 정보
- 원본 비공개 프롬프트·시스템 메시지·내부 추론 및 작업 로그

공개 범위는 **외부에서 독립적으로 이해하고 실행할 수 있는 입력·최종 결과·평가 표면까지**입니다.

세부 공개 원칙은 [`docs/PUBLIC_BOUNDARY.md`](docs/PUBLIC_BOUNDARY.md)를 참고해 주세요.

## 왜 공개하나

운영형 AI를 평가하려면 단순히 답변 문장의 품질만 보는 것으로는 부족합니다. 어떤 행동이 제안되었고, 실제 실행 여부와 결과가 어떻게 달라졌으며, 같은 조건에서 다시 확인할 수 있는지가 중요합니다.

SEA Ops Arena는 이러한 차이를 외부에서도 검증할 수 있도록 **문제·입력·최종 결과·평가·재현 정보**를 공개합니다. 핵심 기술의 내부 구현은 그 공개 표면과 분리합니다.

## 공개 평가 지표

현재 공개판은 하나의 종합점수를 임의로 만들기보다 다음 관찰값을 각각 보여 줍니다.

| 지표 | 의미 |
|---|---|
| 판단 일치율 | 공개 시나리오의 기대 판단과 결과가 일치한 비율 |
| 불필요 실행 | 실행하지 않아야 하는 공개 사례에서 실행이 진행된 횟수 |
| 필요한 실행 누락 | 실행해야 하는 공개 사례에서 실행되지 않은 횟수 |
| 실행 성공률 | 실제 시도된 실행 가운데 합성 환경의 공개 기대 결과와 일치한 비율 |
| 반복 판단 안정률 | 동일 조건의 여러 공개 결과에서 최종 판단이 계속 동일한 사례의 비율 |

가중치를 임의로 섞어 좋은 숫자를 만드는 대신 원래 관찰값을 그대로 공개하는 것을 기본 원칙으로 합니다.

## 개발 로드맵

현재 구현 범위와 이후의 실제 외부 결과 축적, 시나리오 확장, 공개 결과 시각화 계획은 [`docs/ROADMAP.md`](docs/ROADMAP.md)에 정리되어 있습니다.

로드맵 역시 공개 Arena의 기능만 다루며 SEA 내부 개발 계획은 포함하지 않습니다.
